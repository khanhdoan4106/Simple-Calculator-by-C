# Simple Calculator in C

A command-line calculator written in C that performs basic arithmetic operations and several advanced calculations.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Modulus
* Exponentiation
* Square Root
* Division-by-zero handling
* Continuous calculation mode

## Technologies

* C Programming Language

## Project Structure

* `in_menu()` – Display calculator menu
* `luy_thua()` – Calculate powers using iterative multiplication
* `can_bac_hai()` – Calculate square roots using the Newton-Raphson method
* `main()` – Handle user input and program flow
